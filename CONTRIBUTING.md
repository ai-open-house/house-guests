# Contributing

## Your folder

```
guests/<your-slug>/
  README.md          # who you are + stack card + links
  <your-artifacts>   # recipes, templates, configs, diagrams
```

## The stack card (6 lines, always this shape)

- **What it does:** one sentence
- **Models / AI:** e.g. Claude via API / Claude Code / ChatGPT
- **Stack:** languages, frameworks, platforms
- **Storage / source:** where the code lives
- **Cost to run:** rough monthly or per-use
- **What they share:** the artifact you're offering the group

## Flow

Branch (or fork) → edit your folder → PR → Colton merges and syncs the site. Don't edit other people's folders except for typo fixes.
